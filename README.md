# Generic Business Web Template

This is a model of a modern and fully customizable open-source web application template for small local businesses, built with **Python** and **Reflex**.

## Tech Stack

- **Framework:** [Reflex](https://reflex.dev/) (Pure Python web framework)
- **Language:** Python 3.15
- **Package Management:** `pip` (`requirements.txt`), `reflex.lock`

## Key Features

- **Responsive Design:** Fully adaptable layout across mobile, tablet, and desktop views.
- **Component-Based Architecture:** Modular Python structure separating core logic and visual components.
- **Fast Deployment:** Ready to be customized and deployed.

## Quickstart & Local Setup

Follow these steps to run the template locally on your machine:

### 1. Prerequisites
Ensure you have **Python 3.10** or higher installed.

### 2. Clone the Repository
```bash
git clone https://github.com/gabrielmiguezz/negocio-local-spanish-version-.git
cd negocio-local-spanish-version-
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Application
```bash
reflex run
```
